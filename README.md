# Shopstore

Shopstore is a small PHP/MySQL online shopping site built for
Web Technology and Security course project. It sells computer
accessories and demonstrates the **Weak Session IDs** vulnerability.

## File layout

```
shopstore/
├── db.php          MySQLi connection
├── database.sql    Schema + seed data
├── seed.php        One-time seeding for default users
├── index.php       Home page
├── register.php    New account form
├── login.php       Login form, creates the weak SID
├── products.php    Catalog
├── order.php       Place an order
├── admin.php       Admin-only users + orders view
├── logout.php      Deletes the session
├── style.css       styling
├── README.md       this file
```
